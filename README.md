# Mi amor, Camila 💜

Una pequeña página web romántica, creada como un detalle personal y publicada gratis con GitHub Pages.

**Ver la página:** https://luisequeira612-commits.github.io/mi-amor-camila/

## Qué incluye

- Contador del tiempo desde el 30 de octubre de 2026 a las 00:00 (hora de Nicaragua).
- Historia, carta y mensajes personales.
- 100 razones y 100 promesas.
- Sueños compartidos y espacios reservados para fotografías futuras.
- Cartas interactivas, sorpresa aleatoria y pequeño juego.
- Enlace a la canción especial y opción para compartir la página.

## Cómo está construida

- HTML, CSS y JavaScript nativos.
- Sin frameworks, dependencias ni backend.
- Diseño adaptable a teléfonos y computadoras.
- Los cambios se publican automáticamente mediante GitHub Actions y GitHub Pages al actualizar la rama `main`.

## Desarrollo local

Abre `index.html` en un navegador. No hace falta instalar paquetes ni configurar un servidor.
